# James Frysinger

Personal portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

## Overview

This project showcases:

- Work history and featured projects
- Professional profile and summary
- Technology stack and capabilities
- Contact details for inquiries and collaboration
- Responsive layout optimized for desktop and mobile

## Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## Getting started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
```

## Project structure

```text
src/
  app/
    components/
    data/
    types/
  app/page.tsx
public/
  downloads/
  images/
```

## Deployment

This site is designed to be deployed on a modern Node hosting platform such as Vercel or a similar Next.js-compatible environment.
